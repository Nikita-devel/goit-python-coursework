# GoIT Python Developer — coursework

All homework and module projects from the GoIT *Python Developer* programme (2023–2024), merged into one
repository with **full commit history preserved** (`git subtree`). The original repositories are archived.

| Folder | Content |
|---|---|
| [`python-core/`](python-core) | OOP, data structures, CLI assistant, file sorter, algorithms |
| [`python-web/`](python-web) | HTML/CSS/JS, web basics |
| [`data-science/`](data-science) | NumPy, Pandas, scikit-learn, TensorFlow / Keras notebooks |

Team projects from the same programme: [parking-system-api](https://github.com/Nikita-devel/parking-system-api) (team lead) ·
[dedalus_project](https://github.com/Pelmenoff/dedalus_project) (contributor).
